# Paper drafts

Dated PDF snapshots of each report at each milestone, so you can show how the reports developed.

| Draft | Date | What changed |
|---|---|---|
| | | |

**How to add a snapshot:**

1. Download the latest PDF from the Actions tab (`interim-pdf` or `final-pdf`; see `../README.md`).
2. Save it here as `interim-YYYY-MM-DD.pdf` or `final-YYYY-MM-DD.pdf`.
3. Add a row to the table above, and update the "Latest paper PDF" links in the main README.
4. Commit with `paper: interim draft YYYY-MM-DD` (or `final draft`).

These are your own PDFs, so they're committed. That's unlike `readings/pdfs/`, which is git-ignored.

# Paper drafts

Dated PDF snapshots of the paper at each milestone, so you can show how the paper developed.

| Draft | Date | What changed |
|---|---|---|
| | | |

**How to add a snapshot:** download the latest PDF from the Actions tab (see `../README.md`), save it here as `draft-YYYY-MM-DD.pdf`, add a row to the table above, update the "Latest paper PDF" link in the main README, and commit with `paper: draft YYYY-MM-DD`.

These are your own PDFs, so they're committed. That's unlike `readings/pdfs/`, which is git-ignored.

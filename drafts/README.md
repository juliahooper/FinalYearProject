# Drafts

Rough drafts in any format: markdown, Word, text, sketches, exported notes.

- Name files `YYYY-MM-DD-<topic>.<ext>`, for example `2026-11-02-intro-outline.md`.
- Drafts are never referenced by the paper build, so nothing here can break the PDF.
- When a draft becomes real writing, move the text into `paper/sections/` or `paper/notes/`.
